# Extractor Gramatical

App Android (Kotlin + Jetpack Compose) que extrae sustantivos, adjetivos, verbos, adverbios y terminología de un texto pegado. Funciona 100 % sin conexión (español e inglés).

## Compilar con GitHub Actions
1. Sube esta carpeta a un repositorio de GitHub (rama `main`).
2. Ve a la pestaña **Actions** → *Compilar APK* (se ejecuta solo al hacer push, o con *Run workflow*).
3. Al terminar, descarga el APK desde **Artifacts** (`ExtractorGramatical-release`).
